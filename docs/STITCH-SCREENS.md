# FLEG SCORE — per-screen Stitch prompts (paste one at a time)

Run **STITCH-PROMPT.md Part 1 + 2** first to set the theme. Then paste any block below — each one repeats a
short style anchor so it stays on-brand and can be used standalone.

**STYLE ANCHOR (baked into every block):** Dark mobile UI, near-black `#08080F` galaxy backdrop with faint
stars, glassy cards `#13131F`/`#1C1C2E`, FLEG neon-green `#00D95F` primary, red `#FF3B30` for live/cards,
gold/silver/bronze `#FFCF5A`/`#C8D0DA`/`#E0995A` for ranks, Space Grotesk headings + Inter body, tabular
numerals for scores, rounded 20–24px cards, big touch targets, broadcast-sports energy.
